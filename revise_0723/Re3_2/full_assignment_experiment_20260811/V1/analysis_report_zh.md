# V1 IDBO 同协议全面实验报告

本目录使用 V1 优化器本体，但不使用其旧固定场景。V1 和 V2 均求解当前论文的三维 `Scenario.assignment_cost`，名义规模为 **20 架拦截器对 8 个目标**，通信协议、延迟、拓扑、随机种子和动态偏转序列完全一致。

## 主要结果

- 种群规模扫描的运行时间拟合斜率为 0.71；
- 按 $M/N=2.5$ 联合扩大规模时，运行时间拟合斜率为 0.54；
- 名义 $20\times8$ 运行时间为 0.008 s，$160\times64$ 为 0.028 s；
- 静态延迟和拓扑结果与 V2 相同，因为两版使用同一个经过固定点核验的通信层；
- 动态赢家集合变化率为 0.322，低于 V2 的 0.582；
- 100 ms 附加时延时，动态赢家集合一致率为 0.905，所有发生变化的更新都能在 2 s 内恢复；
- 200 ms 时一致率为 0.842，恢复率为 46.4%；400 ms 时一致率为 0.746，恢复率为 2.2%。

V1 的动态一致率较高主要是因为其分配记录变化更少，不能解释为通信共识机制优于 V2。详细的优化质量和运行时间差异见 `comparison/v1_v2_comparison_report_zh.md`。
